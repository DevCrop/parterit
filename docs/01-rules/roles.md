# 역할 분담 (Roles)

> 각 역할의 책임 범위와 산출물을 정의. 상세 행동 지침은 `.claude/agents/<role>.md`에.

## 역할 매트릭스

| 역할 | 책임 | 주요 산출물 | 의존하는 역할 | 에이전트 |
|---|---|---|---|---|
| 브랜딩 | 톤앤매너, 컬러, 로고, 타이포 일관성 | 브랜드 가이드 | — | `branding.md` |
| 기획 | 요구사항 정리, 레퍼런스 수집, 자료 분석 | 기획서, IA, 와이어프레임 | 브랜딩 | `planner.md` |
| 관리자 디자이너 | 시안, 레이아웃, 비주얼 디테일 (관리자) | 디자인 시안 | 브랜딩, 기획 | `designer-admin.md` |
| 홈페이지 디자이너 | 시안, 레이아웃, 비주얼 디테일 (홈페이지) | 디자인 시안 | 브랜딩, 기획 | `designer-brand.md` |
| 퍼블리셔 | 마크업, 스타일, 반응형 | HTML/CSS, 컴포넌트 | 디자이너 | `publisher.md` |
| 개발자 | 기능 구현, 상태관리, API 연동 | 동작하는 코드 | 퍼블리셔, 기획 | `developer.md` |
| 서버 운영 | 배포, 인프라, 도메인, SSL, 모니터링 | 동작하는 배포 | 개발자 | `server-ops.md` |

## 협업 원칙

1. **상위 역할의 결정은 하위 역할이 따른다** (브랜딩 → 디자인 → 퍼블 → 개발).
2. 하위 역할이 상위 결정에 이슈를 발견하면 **변경 요청**으로 올린다 (자체 판단 금지).
3. 모든 역할은 **자기 영역 외에는 손대지 않는다**.
4. 역할 간 경계가 애매하면 `docs/04-history/decisions.md`에 결정 근거 기록.

## 고객 원본 자료 규칙

- 고객이 보내준 모든 원본은 **무조건 `sources/`** 폴더에 보관.
- 가공한 결과물만 `workspace/`에 둠.
- 원본 절대 수정 금지 (덮어쓰기 금지).
