# 파트너잇 브랜드 가이드

## 현재 상태

- 작업 단계: 메인·서브페이지와 관리자 화면의 저해상도 와이어프레임
- 임시 화면 표현: 흑백·회색조, 텍스트와 이미지 대신 구조 자리표시자 사용
- 로고: 텍스트 워드마크 파트너잇
- 실제 컬러, 폰트, 사진, 카피: 미정. 전달받은 뒤 확정

## 적용 원칙

- 실제 브랜드 컬러나 메시지를 임의로 만들지 않는다.
- 공개 페이지는 정보 위계와 섹션 순서만 확인할 수 있게 유지한다.
- 관리자 화면은 공통 CMS 기능을 보존하고 회색조 와이어프레임으로 표시한다.
- 신규 콘텐츠 제공 후 공통 SCSS 토큰과 메뉴 구조를 먼저 갱신한다.
