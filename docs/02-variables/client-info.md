# 파트너잇 프로젝트 정보

- 프로젝트명: 파트너잇
- 산출물: 반응형 공개 사이트와 관리자 CMS
- 현재 단계: 페이지 구조 와이어프레임
- 페이지 내용·메뉴명·연락처·로고 파일·도메인: 전달 대기

## 현재 구조

- 공개: 홈, 기존 서브페이지 경로, 문의, 법적 안내
- 관리자: 기존 게시판, 배너/팝업, 사이트 정보/SEO, 계정 관리
- 실제 콘텐츠가 전달되면 메뉴와 페이지 분류를 새로 확정한다.

## 범위 원칙

- 기존 고객 전용 카피와 시각 요소는 공개 화면에서 사용하지 않는다.
- 공통 CMS 로직과 프로젝트 제공 원본(sources/)은 보존한다.
- DB·계정·도메인·운영 설정은 별도 지시 전까지 유지한다.
