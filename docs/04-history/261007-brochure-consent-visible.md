# 소개서 신청 수집·이용 안내 상시 표시

## 요구사항
- 요청: 수집·이용 내용을 펼치는 조작 없이 모두 표시.
- 현재: details/summary로 초기 숨김.
- 기대: 모달이 열리면 안내 본문이 문서 흐름에 항상 표시됨.
- 유지: 동의 체크박스, 수집 문구, 보유기간 설정, 개인정보처리방침 링크.
- 제외: AJAX/DB/다운로드 동작 변경.
- 제약: 작은 화면에서 모달 자체 스크롤을 유지하고 별도 접힘/내부 스크롤은 만들지 않음.

## 영향 분석
- Backend: 출력 PHP 태그만 변경, API 유지.
- Frontend: partnerit-brochure-modal.php 및 _partnerit-brochure.scss.
- Data: 변경 없음.
- i18n: 원문 변경 없음.
- Test: PHP lint, 빌드, 1440/390/320 모달 안내 가시성 및 제출 버튼 접근.
- Docs: 컴포넌트 카탈로그 및 본 이력.

## 변경 계획
1. 수정 파일: 모달 PHP 및 해당 SCSS.
2. 연관 파일: 기존 폼 primitive/JS는 유지. 카탈로그 재사용.
3. 호출 흐름: 공통 다운로드 버튼 → 모달 → 펼침 없는 안내 → 기존 제출.
4. DB 영향: 없음.
5. 기존 기능 영향: 접기/펼치기만 제거.
6. 리스크: 안내 높이 증가. 기존 dialog의 max-height/스크롤로 대응.
7. 검증: 접기 요소 0개, 안내 전체 렌더 및 가로 넘침 없음, 제출 버튼 스크롤 접근.
8. 문서: 이력에 결과 추가, 카탈로그 수정.

## 결과
- #1/#19 기존 공통 모달 재사용, #10/#17 기존 간격·색상 토큰과 타이포 유틸 사용.
- details/summary를 일반 div와 제목으로 변경. 모바일 공통 br 숨김 영향이 있어 안내 항목을 개별 p로 분리해 줄 단위 가독성 유지.
- 기능: 접기 조작 없이 내용 표시, 필수 동의 및 제출 로직 유지.
- 코드: npm run build 오류/경고 0, PHP lint 및 git diff --check 통과.
- 데이터: DB/API 변경·테스트 접수 없음.
- UI/테스트: Playwright 1440/390/320px에서 접기 요소 0, 안내 가시성, 모달 가로 넘침 없음, 제출 버튼 스크롤 접근 확인.
- 한계: 작은 화면은 모달 전체를 스크롤하여 읽음. 실서버에는 아직 미반영.
